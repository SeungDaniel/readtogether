# 성경 함께 읽기 봇 사용설명서

## 📖 무엇을 할 수 있나요?

매일 정해진 시간에 **오늘의 성경 본문**이 공동체 채팅방에 자동으로 발송됩니다.

## 🎯 사용 방법

### 1. 메시지 받기
- 매일 아침 (기본 08:00) 봇이 오늘 읽을 본문을 보내줍니다
- 성경 구절, 핵심 말씀, 참고자료 링크가 포함됩니다

### 2. 읽음 인증하기
1. 본문을 읽습니다
2. 메시지 하단의 **[✅ 읽었어요]** 버튼을 클릭합니다
3. "DAY X 읽음 인증 완료!" 알림을 받습니다

> 💡 읽음 인증은 선택사항입니다. 부담 없이 참여하세요!

## 📚 지원하는 성경책

| 책 | 기간 |
|-----|------|
| 요한복음 | 66일 |
| 이사야 | 94일 |

## ❓ 자주 묻는 질문

**Q: 버튼을 눌렀는데 반응이 없어요**
- 인터넷 연결을 확인해주세요
- 잠시 후 다시 시도해보세요

**Q: 오늘 메시지를 놓쳤어요**
- 채팅방을 위로 스크롤하여 과거 메시지를 확인할 수 있습니다

**Q: 다른 책으로 바꾸고 싶어요**
- 공동체 관리자에게 요청해주세요

## 📞 문의

메시지가 오지 않거나 문제가 있다면 공동체 관리자에게 연락해주세요.
